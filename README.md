# Dennis Schwarz | Professional Profile

Persönliche berufliche Profilseite mit React, Vite, Tailwind CSS, Framer Motion und Lucide Icons.

## Lokal starten

```bash
npm install
npm run dev
```

## Produktions-Build testen

```bash
npm run build
npm run preview
```

## GitHub Pages

Das Projekt ist für dieses Repository konfiguriert:

- Repository: `iBS-Schwarz/dennis_schwarz_profile`
- Base Path: `/dennis_schwarz_profile/`
- Deployment: GitHub Actions

Unter **Settings > Pages > Build and deployment** muss als Quelle **GitHub Actions** ausgewählt sein.
